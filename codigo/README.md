# Código de FLEXI

En esta carpeta se almacenará el código fuente utilizado para programar el microcontrolador ESP32.

## Herramienta de programación
Arduino IDE.

## Componentes programados
- ESP32
- Sensor MPU6050
- Buzzer

## Funcionamiento
El programa recibe los datos del sensor MPU6050, procesa los cambios de inclinación y activa una alerta sonora mediante el buzzer cuando se cumple la condición establecida.
